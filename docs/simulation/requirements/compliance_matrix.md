# Simulation Compliance Matrix

This matrix is the compact review map for the split simulation requirements. It maps requirement IDs or contiguous requirement groups to the implementation surface, test surface, current status, and any known gap.

Status values:

- `implemented`: code and focused tests exist for the current first-pass scope.
- `partial`: first-pass support exists, but the full requirement is not complete.
- `open`: implementation work is required and tracked as a current gap.
- `deferred`: valid requirement intentionally outside the first implementation pass.
- `blocked`: Charter ambiguity prevents definitive implementation without assumptions.
- `documentation`: requirement is satisfied by repository documentation or structure review.
