# Versioning And Change Log

## Versioning Policy

- The canonical source is `charter/charter.md`.
- Supplemental documents must track the canonical Charter text rather than evolve independently.
- Record substantive changes with date, editor, and summary.
- If a derivative preserves ambiguity from the Charter, note that explicitly rather than silently resolving it.
