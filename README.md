# Jefferson Mark III

Repository for the Jefferson Mark III charter, supporting annotations, and machine-readable derivatives.

## Structure

```text
jefferson-mark-iii/
├── README.md
├── LICENSE
├── charter/
│   ├── charter.md
│   ├── charter.pdf
│   └── versioning.md
├── derivatives/
│   ├── simulation/
│   │   ├── charter_sim.yaml
│   │   ├── schema.md
│   │   └── examples/
│   └── explainers/
│       ├── plain_language.md
│       ├── deep_explainer.md
│       └── faq.md
├── annotations/
│   └── annotated_charter.md
└── governance/
    ├── contribution_guidelines.md
    └── change_proposal_template.md
```

## Purpose

- `charter/` holds the canonical charter and its formal version history.
- `derivatives/` holds adapted formats for simulation, education, and external communication.
- `annotations/` holds rationale and commentary tied to the charter text.
- `governance/` defines how the repository evolves.
