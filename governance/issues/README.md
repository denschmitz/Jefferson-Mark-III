# Governance Issues

This directory stores issue drafts for substantive design, interpretation, and implementation questions in the repository.

Use issue drafts here when a concern is concrete enough to track on its own, but not yet mature enough to become a formal change proposal.

Canonical text changes still flow through `charter/charter.md` and the normal review process. These issue files exist to capture gaps, tensions, and design questions in a durable form before specific amendment language is proposed.
